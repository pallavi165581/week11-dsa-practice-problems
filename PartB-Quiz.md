# Part B — Quiz Answers

| Q | Answer | Reason |
|---|--------|--------|
| 1 | **B** | A data structure defines how data is organized, stored, and accessed efficiently for specific operations. |
| 2 | **D** | Non-primitive structures are built by combining primitive types and store collections of values (arrays, lists, etc.). |
| 3 | **C** | Accessing an array element at a known index is O(1) — direct address computation. |
| 4 | **C** | A loop of n iterations nested inside another loop of n iterations runs n × n = O(n²). |
| 5 | **B** | Two independent sequential loops of m and n iterations add: O(m + n). |
| 6 | **A, C, D** | Deletion, Traversal, and Updating are standard data-structure operations. Debugging and Compilation are not. |
| 7 | **C** | Sorting by date prioritizes O(log n) binary-search range queries, which fits "queries frequent, inserts rare." |
| 8 | **D** | A sorted array gives O(log n) binary search and maintains order; best when inserts/deletes are rare. |
| 9 | **C** | Two pointers exploit sorted/exploitable ordering to skip brute-force pairwise comparisons. |
| 10 | **C** | Sliding window avoids recomputing overlapping ranges, typically cutting O(n·k) or O(n²) down to O(n). |
